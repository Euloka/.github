# Euloka

**Explore experiences, events and people around Bhutan.**

<sub>BASED IN BHUTAN</sub>

</div>

---

Euloka helps you find what's happening around Bhutan, from local experiences and
festivals to the people who host them. Use it to see what's on, book a spot and
meet the community.

### What we build

- **Euloka app**: a Flutter mobile app for browsing experiences, events and a
  community feed.
- **Euloka API**: the backend behind the app, built with Hono on Next.js and
  hosted on Vercel, with data in Neon Postgres.
